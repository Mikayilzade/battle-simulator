# Epohi visual reference — 2026-10-03

Status: **current preference / working visual reference, not final art direction**.

The user reviewed the newer local Epohi rebuild and said this visual language feels
more familiar and comfortable than the current Battle Simulator presentation.

Until better personal references are supplied, use this Epohi direction as the primary
visual anchor for the Visual Style Lab.

## What the user currently likes

### Terrain / map readability

The newer Epohi map is a useful reference because:

- terrain types read immediately as distinct cells;
- grass/plains, forest, mountain/hill, desert, water and special locations have
  recognizable silhouettes/icons;
- terrain is colorful enough to scan quickly without becoming noisy;
- the square grid remains obvious and usable;
- map information density is high but still readable;
- terrain symbols sit inside the cell rather than turning the whole UI into a debug table;
- water, mountains and forests feel like terrain first, not abstract buttons.

For Battle Simulator experiments, preserve the idea that the map should be instantly
legible before attempting more elaborate isometric or realistic art.

### Unit presentation

The newer Epohi people/units are a better reference than the current Battle Simulator
debug markers because:

- units look like small people/figures rather than coded tokens;
- silhouettes are compact and readable at map scale;
- color/faction treatment is visible without hiding the character form;
- small badges/markers can carry secondary state;
- unit art does not overpower the terrain;
- selection/path overlays remain readable around the unit.

For early Battle Simulator unit variants, prioritize **small recognizable figures or
compact formations** over circles/diamonds with text abbreviations.

### General screen composition

Useful aspects of the newer Epohi rebuild:

- map occupies most of the screen;
- contextual information lives in a side panel;
- top bar carries compact strategic state;
- bottom area is reserved for major turn/action controls;
- the map remains the visual center;
- UI panels have a warm parchment / dark-green strategy-game language rather than a
  developer-tool look.

## What is NOT being copied

This is a visual reference, not a request to duplicate Epohi exactly.

Do not assume Battle Simulator must keep:

- the same colors;
- the same icons;
- the same exact terrain art;
- the same panel proportions;
- the same map generator;
- the same resource HUD;
- the same unit sprites.

Use the reference to understand the user's preferred **clarity, density, scale and
strategy-game feel**.

## Important visual preference learned

The user currently prefers:

- familiar square-grid strategy readability over an abstract technical grid;
- visible terrain identity over generic flat tiles;
- character-like unit markers over coded circles/diamonds;
- a map-first composition;
- concise contextual panels;
- visual familiarity similar to the newer local Epohi rebuild.

If later references look better to the user, add them to the reference set and update
this note rather than treating this document as final art direction.

## For Orca / Visual Lab work

When generating options:

- include several styles that preserve Epohi-like clarity even if they differ in art;
- include 2D and 2.5D options, but do not force isometric presentation if it reduces
  readability;
- create terrain and unit variants that can be compared side by side;
- favor genuinely different art directions, not tiny palette tweaks;
- keep stable IDs so the user can shortlist exact variants;
- keep rejected but interesting variants in the archive for possible reuse.

The user may provide more screenshots later. Those future references should be treated
as additive and may supersede parts of this note.
